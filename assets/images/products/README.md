# Fotos de los platos

Guarda aqui una imagen por plato. El archivo debe tener el mismo nombre que la ruta `image` de cada producto en `js/data/menu-data.js`.

Ejemplos:

- `chaufa-de-pollo.jpg`
- `pollo-entero-a-la-brasa.jpg`
- `chicha-morada-jarra-1-l.jpg`

Mientras una foto no exista, la pagina muestra una plantilla que dice `Foto del plato`. Puedes usar archivos `.jpg`, `.jpeg`, `.png` o `.webp`; si cambias la extension, actualiza tambien la propiedad `image` del producto correspondiente.
